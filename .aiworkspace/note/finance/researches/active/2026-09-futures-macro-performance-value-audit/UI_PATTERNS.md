# 사용자 해석과 화면 개선 방향

Date: 2026-09-21
Status: 제안, 미구현

## 각 영역에서 끝낼 질문

| 현재 영역 | 사용자의 질문 | 주의할 오해 |
|---|---|---|
| 시장 재가격화 해석 | 지금 가장 두드러진 가격 변화는 무엇인가? | 경제적 원인을 규명했거나 미래를 예측한 것으로 읽지 않기 |
| 선물군별 방향 정렬 | 오늘의 변화가 며칠째 이어지고 다른 자산도 동조하는가? | 1D/5D/20D를 향후 기간으로 읽지 않기 |
| 최근 체제 이력 | 최근 분류가 얼마나 자주 바뀌고 어떤 상태가 반복됐는가? | 같은 색이 오래 이어졌다고 다음에도 지속될 확률이 높다고 판단하지 않기 |

## 현재 화면을 쉬운 말로 옮긴 예

> 국채선물 약세가 최근 1일·5일·20일에 걸쳐 나타납니다. 주가지수는 오늘 강하지만 최근 5일의 위험선호는 아직 뚜렷하지 않습니다. 다른 핵심 자산군의 동조도 약합니다. 지금은 금리에 민감한 자산을 먼저 점검하되 시장 전체의 방향을 한쪽으로 확정할 근거는 약합니다.

후속 관측은 (1) 국채 약세가 계속되는지, (2) 달러 압력이나 주가지수 약세가 동반되는지, (3) 국채가 반등해 기존 해석을 약화시키는지다. 이는 판단에 필요한 확인 목록이지 매수·매도·비중 변경 지시가 아니다.

## 권고하는 화면 흐름

1. ‘지금 먼저 확인할 것’: 가장 뚜렷한 관측 한 문장 + 관련 자산 + 관측 시각.
2. ‘왜 그렇게 보는가’: 가격 근거 → 선물군 의미 → 동조 여부. 수치와 출처는 펼쳐 볼 수 있게 한다.
3. ‘무엇을 보면 생각을 바꿀 것인가’: 현재 해석의 지속/반전 조건을 앞선 근거와 연결한다.
4. 이력은 보조 영역으로 두고 혼재의 이유(저신호·축 간 충돌·단일 축)를 구별한다. 분류 체계 변경은 기준 검증을 거친다.

문구 제안:

- 1D / 5D / 20D → ‘최근 1일 / 최근 5거래일 / 최근 20거래일’, 잠정치 포함 여부 명시.
- ‘성장 기대’ → ‘경기민감 자산 흐름’, ‘물가 압력’ → ‘원자재 가격 압력’ 또는 명확한 대리 지표 설명.
- ‘혼재 · 지속 중’ → 현재 사례에서는 ‘금리 부담은 이어지지만 다른 자산의 확인은 약함’처럼 범위를 밝힌다.
- ‘반대 근거 없음’ → ‘뚜렷한 반대 신호는 없지만 다른 자산의 확인도 약함’처럼 증거 부족을 확신으로 읽지 않게 한다.

판단 질문과 다음 확인 행동을 개선하는 것이 목적이다. job/row/status 중심 갱신 진단 패널을 추가하는 제안은 하지 않는다.
