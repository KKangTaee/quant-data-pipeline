State: complete

## 이걸 하는 이유?

`선물매크로` 화면이 최신 관측과 완료 일봉을 구분하면서도 사용자가 지금 무엇이 변했고,
그 변화에 예측력이 있는지를 빠르게 판단하게 만들어야 한다. 현재는 상단 공간, 설명형 문구,
검증 상태 표현 때문에 실제 결론보다 방법론이 더 앞에 보인다.

## 질문

1. 현재 세션 데이터가 없을 때 refresh와 화면은 어떤 데이터를 사용해야 하는가?
2. 1D / 5D / 20D는 방법 안내가 아니라 어떤 관측 결과를 말해야 하는가?
3. 5D 검증 게이트가 `NO_EDGE`인 이유는 데이터 부족인가, 검증 완료 후 음성 결론인가?
4. 상단 hero와 `Next Check`를 어떻게 정리해야 판단 시간이 줄어드는가?

## 범위

- 현재 구현, 실제 DB snapshot, refresh routing, 화면 copy/레이아웃 감사
- 구현 접근안과 추천 디자인 원칙 제시
