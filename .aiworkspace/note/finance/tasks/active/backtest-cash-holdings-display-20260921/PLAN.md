# 현금·보유 구성 표시 수정

## 이걸 하는 이유?
전액 현금으로 전환해도 기존 SOXX·MTUM이 목표로 표시되고 변경 전 종목과 변경 후 현금이 합산된다. 사용자 승인에 따라 기존 표와 카드의 의미를 바로잡는다.

1. Python read model의 전후 시점·빈 목록·비용 기준을 수정하고 기존 React/fallback 표제를 맞춘다. 완료 조건은 전액/부분 현금과 재매수 구성의 정확한 표시다.
2. 회귀 테스트, Browser QA, 문서 정렬, 리뷰 후 커밋한다. 전략 계산/리밸런싱 날짜, DB, registry는 변경하지 않는다.
