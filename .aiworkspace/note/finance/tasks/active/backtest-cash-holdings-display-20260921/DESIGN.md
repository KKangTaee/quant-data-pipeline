# 설계

End Ticker/Balance는 변경 전, Next Ticker/Balance와 Cash는 변경 후다. 빈 Next 목록과 필드 누락을 구분한다. 최신 전액 현금도 유효한 목표로 유지한다. 변경 전 현금은 동일 gross 평가액에서 End Balance 합을 빼서 복원하며, 변경 후는 종목 잔고와 현금 합을 기준으로 표시한다. 성과 곡선의 비용 차감 Total Balance로 gross 종목 비중을 나누지 않는다.

리밸런싱일 카드에는 변경 전/후를, 유지일에는 평가 시점 보유/최근 리밸런싱 후 구성을 표시한다. 표는 현금 포함 비중과 추가/제외 종목을 보여준다.
