## 승인된 표현 계약

카드 제목은 다음 세 개를 그대로 사용한다.

- `1D · 지금 새로 생긴 변화`
- `5D · 현재 단기 방향`
- `20D · 기존 배경과의 관계`

`현재 관측 · 1D/5D/20D` eyebrow는 제목과 중복되므로 제거한다.

본문은 항상 두 문장으로 구성한다.

1. 실제 관측 결과: 어떤 family가 새로 나타남·지속·반전·정렬·엇갈림 상태인지 설명한다.
2. 판단 의미: 그 결과가 단기 전환 또는 중기 배경 정렬을 말할 수 있는지, 부족하다면 무엇이
   함께 움직이지 않았는지 설명한다.

## 생성 원칙

- 기존 `semantic_label`과 material threshold 판정만 사용한다.
- 자유 생성 문장이 아니라 상태별 결정적 template을 사용한다.
- `기존 방향 지속:` 같은 분류표 문구와 `확인합니다` 같은 안내형 문구는 쓰지 않는다.
- 하루 변화만으로 단기 방향 전환을 확정하거나, 단일 family만으로 전체 정렬을 과장하지 않는다.
- 20D는 5D의 현재 semantic label을 기준으로 기존 배경과의 지속 또는 반전을 설명한다.

## 제외 범위

- family 계산식, z-score 임계값, regime 판정 변경
- 5거래일 검증 상태와 publication threshold 변경
- 새로운 데이터 수집·저장·진단 UI
