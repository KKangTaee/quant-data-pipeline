# 경기 국면 자산 자료 갱신 기준일 수정

## 이걸 하는 이유?

월간 경기 국면은 전월 말이 맞지만, 같은 화면의 일별·주별 자산 자료까지
전월 말 기준으로 검사해 `최신 데이터 반영`이 실제 수집을 건너뛴다.
사용자가 승인한 범위는 월간 기준 유지와 자산 자료의 현재 날짜 기준 갱신이다.

## 실행 계획

- [x] 1차: 날짜가 다른 월간 국면/자산 자료의 회귀 테스트를 먼저 실패시키고,
  `app/jobs/overview_actions.py`의 자산 freshness 사전·사후 검사만 수정한다.
- [x] 2차: 관련 Python 테스트, 실제 버튼 실행과 DB 재조회로 월간 snapshot 보존과
  자산 데이터 최신화를 확인한다. Browser QA screenshot은 generated artifact로 둔다.
- [x] 3차: 결과·제한을 기록하고 이번 변경만 커밋한다.

## 완료 조건

- 월간 국면 snapshot의 목표일은 직전 완결 월말이다.
- 자산 사전·사후 검사는 요청 기준일(생략하면 오늘)을 사용한다.
- 수집이 데이터를 갱신하지 못했을 때 지난 월말 기준으로 성공 판정하지 않는다.
- 기존 daily/weekly 허용 주기, provider/write 경계, 화면 구조를 보존한다.
