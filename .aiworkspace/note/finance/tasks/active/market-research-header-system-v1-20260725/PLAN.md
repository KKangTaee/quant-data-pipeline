# Market Research Header System V1

Status: Design approved in visual review
Date: 2026-07-25

## 이걸 하는 이유?

Market Research의 `경제 사이클`, `선물 매크로`, `심리`, `일정`은 같은 사용자 흐름에 속하지만 상단 헤더의 제목 크기, 여백, 카드 구조, 메타정보 위치가 서로 달라 화면을 이동할 때 다른 제품처럼 느껴진다.

이번 작업은 화면별 정보량을 억지로 맞추지 않으면서 공통 타이포와 정보 위계를 적용해, 사용자가 어떤 화면에서도 `현재 판단 -> 핵심 설명 -> 기준 정보`를 같은 순서로 읽게 만드는 것이 목적이다.

## 잠정 Roadmap

1. `1/3차` — 공통 헤더 구조와 상태 표현 설계 확정
   - 완료 조건: 네 화면의 공통 구조, 가변 슬롯, 반응형 규칙, 비변경 범위를 사용자와 합의한다.
2. `2/3차` — 공통 React 헤더와 네 화면 어댑터 구현
   - 완료 조건: 기존 데이터 의미와 action dispatch를 보존한 채 네 화면이 공통 헤더를 렌더링한다.
3. `3/3차` — 정적 빌드, 회귀 검증, 실제 Browser QA와 문서 정렬
   - 완료 조건: 1280px, 760px, 420px에서 정보 위계·overflow·버튼 동작을 확인하고 QA 스크린샷과 문서를 남긴다.

## Scope

- `경제 사이클`, `선물 매크로`, `심리`, `일정` React workbench의 첫 번째 헤더
- 공통 제목, eyebrow, kicker, 설명, 우측 사실 카드, 하단 메타 칩
- 선택적 action 영역과 화면별 사실 카드 1~3개
- desktop / tablet / mobile 반응형 배치
- 네 Vite component의 정적 빌드 산출물 갱신

## Out Of Scope

- 경제사이클 확률, 선물매크로 판단, 심리 해석, 일정 우선순위 계산 변경
- payload schema 또는 DB / loader / collector 변경
- 헤더 아래 본문 카드와 탐색 구조의 전면 개편
- 새로운 갱신 진단 패널 또는 운영 상태 표 추가

## Stop Condition

- 사용자가 문서화된 설계를 검토하고 구현 계획 진행을 승인하기 전에는 화면 코드를 수정하지 않는다.
