# Economic Cycle Interpretability & Refresh v1

## 이걸 하는 이유?

경제사이클 화면은 현재 국면과 조건부 다음 방향을 계산하고 있지만, 갱신 기준이 구형 월중 파이프라인에 묶여 있고 RTDSM 현재 국면과 과거 8지표 설명이 혼합되어 사용자가 결과를 신뢰하기 어렵다. 이번 작업은 계산 결과를 더 많이 노출하는 것이 아니라 사용자가 `현재 상태 → 최근 변화 → 전환 가능성 → 자산별 확인`을 한 번에 해석하도록 제품 흐름을 정렬한다.

## 전체 개발 흐름

1. 공식 월말 국면 기준으로 Data Freshness와 수동 갱신 경로를 교체한다.
2. RTDSM 4지표의 품질·비교기간·현재 근거 계약을 read model에 명시한다.
3. 현재 국면, Cycle route, 전환압력, 판단근거, 12개월 흐름 UI를 승인 시안으로 재구성한다.
4. 자산 카드는 기존 정보 구조를 보존하면서 공통 경제 배경 중복과 원자재의 금 중복만 제거한다.
5. Python/React 회귀검증과 실제 Streamlit Browser QA를 수행하고 문서를 정렬한다.

## 완료 조건

- 최신 공식 월말 스냅샷이 있으면 Data Freshness가 매일 갱신 필요로 표시되지 않는다.
- 수동 갱신은 legacy 17지표 intramonth가 아니라 RTDSM 4지표 수집과 confirmed monthly publication을 사용한다.
- 수동 갱신 후 React의 로딩 상태가 성공·부분 성공·실패 결과에서 모두 해제된다.
- 1·3·6개월 카드는 비교 월, 종합 변화, 개선 지표 수를 명시하고 분모가 4로 표시된다.
- `회복 7개월`과 이전 화면의 위축 판정 차이가 방법론 변경으로 설명된다.
- Cycle route는 하늘색 톤과 정상 비율을 사용하고 모든 후보와 조건부 최우선 경로를 구분한다.
- 전환압력 상승/하락 요인이 분리되고 조건부 국면 확률의 의미가 명확하다.
- 현재 국면 근거는 RTDSM 현재 상태와 일치하며 legacy 8지표 근거와 섞이지 않는다.
- 12개월 흐름은 범례, 월, 전환 확인 여부를 hover/focus에서 설명한다.
- 자산별 기존 카드 구조·수치·설명은 유지되고 반복된 공통 배경과 원자재의 금 중복만 제거된다.
- 자산의 1개월·3개월 수치는 별도 칸, 양수 녹색·음수 빨간색·0 회색으로 표시되며 방향색이라는 범례가 있다.
- 월별 신호 활용법과 방법론/품질 disclosure의 닫힌 상태 디자인이 동일하다.

## 이번 작업에서 하지 않는 일

- 예측 모델 재학습 기준이나 확률 산식을 변경하지 않는다.
- NBER 공식 판정, 정확한 전환 월 예측, 매매 신호를 추가하지 않는다.
- 자산별 pathway 계산식과 기존 측정 데이터는 변경하지 않는다.
- `financial_advisor`, Backtest, Today 등 다른 화면은 변경하지 않는다.
