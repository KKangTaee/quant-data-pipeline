# 장기 미갱신 가격 수집 복구

## 이걸 하는 이유?
GTAA 종료일 2026-09-18을 요청했지만, 44일 오래된 IAU/IEF/MTUM/QUAL/TLT/USMV가 수집 전에 제외되어 결과가 2026-08-05에 멈춘다.

사용자는 갱신 대상 로직 수정 후 현재 데이터 복구를 승인했다. `AU`는 직전 확인된 `IAU`로 해석한다고 안내했다.

1. age-only 추정을 수집 제외 근거에서 제거하고 회귀 검증한다.
2. 기존 OHLCV ingestion으로 6개 ETF의 2026-08-06~09-18 데이터를 복구한다.
3. 같은 GTAA 설정으로 재실행하여 실제 종료일과 전체 종목 최신일을 확인하고 변경을 커밋한다.

기존 worktree codex/backtest-dev를 사용한다. UI 구조, 전략 계산, 스키마, registry/saved 변경은 범위 밖이다.
